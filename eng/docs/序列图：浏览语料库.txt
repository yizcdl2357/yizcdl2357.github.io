```mermaid
sequenceDiagram
    actor User as 用户
    participant CorpusPage as GitHub Pages /eng 语料库界面
    participant API as Railway Backend API
    participant CORS as CORS Policy
    participant ParagraphService as ParagraphService
    participant ParagraphRepository as MySQLParagraphRepository
    participant DB as 云端MySQL

    User->>CorpusPage: 进入语料库界面
    CorpusPage->>API: GET /api/paragraphs?sort=collectionCount<br/>Origin: https://yizcdl2357.github.io
    API->>CORS: validateOrigin(origin, credentials)
    CORS-->>API: 允许精确 Origin 并返回凭据头
    API->>ParagraphService: searchParagraphs(sort=collectionCount)
    ParagraphService->>ParagraphRepository: findAllWithCollectionCounts()
    ParagraphRepository->>DB: 查询共享语段并统计收藏数
    DB-->>ParagraphRepository: 返回按收藏数排序的语段列表
    ParagraphRepository-->>ParagraphService: 返回语段列表
    ParagraphService-->>API: 返回语段列表
    API-->>CorpusPage: 返回共享语段列表
    CorpusPage->>CorpusPage: formatParagraphPreview(maxLength=300)
    CorpusPage-->>User: 展示正文预览、主题、标签和收藏数
```

语料库展示规则表
规则编号	条件	系统行为
B1	展示语料库列表	每篇语段不显示标题
B2	正文字符数大于300	仅显示前300字并追加省略号
B3	正文字符数不超过300	显示完整正文
B4	不同设备访问语料库	通过同一Backend API读取同一云端MySQL数据
B5	GitHub Pages 请求 Railway API	后端只允许 https://yizcdl2357.github.io Origin，支持必要的 CORS 预检与凭据
B6	展示迁移例句	正文、主题和标签来自云端 MySQL，作者统一为系统用户，不展示本地用户/收藏迁移结果
